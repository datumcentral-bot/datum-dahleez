# Datum Dahleez Store

Professional interior design e-commerce platform serving residential, office, hospital, and business clients worldwide.

## 🌍 Live Site
**URL:** https://datumcentral-bot.github.io/datum-dahleez

## 🏢 Business Focus
- **Residential** - Home interior design and decoration
- **Offices** - Corporate workspace furniture and setups
- **Hospitals** - Medical facility interior solutions
- **Podcast Studios** - Professional audio production setups
- **Co-working Spaces** - Shared workspace furniture and design
- **Branding** - Custom signage, vinyl, and visual identity

## 🛠️ Tech Stack
- **Static Site:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting:** GitHub Pages (free)
- **E-Commerce:** Custom JavaScript shopping cart
- **Payments:** Manual payment processing (extensible to Stripe)
- **Analytics:** Google Analytics (free)
- **Domain:** Custom domain ready

## 🔧 Setup Instructions

### For GitHub Pages (Recommended)
1. Fork this repository
2. Go to Settings → Pages
3. Select branch: `main`
4. Save and wait for deployment
5. Visit: https://datumcentral-bot.github.io/datum-dahleez

### For Local Development
```bash
# Clone the repository
git clone https://github.com/datumcentral-bot/datum-dahleez.git

# Navigate to project directory
cd datum-dahleez

# Start local server (Python)
python -m http.server 8080

# Or use Node.js
npx serve -s . -p 3000
```
